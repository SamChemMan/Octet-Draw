# Decimals on every live value (#77, for 1.1.3)

Branch `item/b-77`, from `release-1.1.3` (f06d1b49), for Octet Draw 1.1.3 (Friday 20 November 2026). Plan written
19 November 2026.

Stefan asked in #77 to set the number of decimal places of a live value. In 1.1.2, Decimals in the Properties panel
reaches only Exact mass, Molecular weight and m/z. A live value already in the drawing keeps the places it was
added with, and nothing changes them.

## What it must do

1. Decimals in the Properties panel applies to every row with a number that the panel or a live value shows:
   Exact mass, Molecular weight, m/z, tPSA, Boiling point, Melting point, Critical temperature, Critical pressure,
   Critical volume, Heat of formation, Gibbs energy, Henry's law (log), logP, Molar refractivity, logS and pKa.
2. Standard (no Decimals set) keeps each row's own places, as today: 4 for Exact mass, 2 for Molecular weight, m/z,
   tPSA, critical pressure, heats, Henry's law, logP, MR and logS, 1 for the temperatures, critical volume and pKa.
3. A live value already in the drawing can take other decimals: Decimals (Standard, 0 to 8) on the picked live values,
   in the Actions panel and in the right-click menu. It works on one value, on several, and on every one ⌘A picks,
   as Hide property names does.
4. The command is `caption.places.N` (N 0 to 8) and `caption.places.standard`. AI apps reach it by run_command, and
   edit takes `decimals` as it takes `names`.
5. The decimals are kept in `property.attrs.places`, as Add to drawing already writes them. .oct and CDXML keep them
   (LIVE_ATTRS has `places`). Standard removes the attribute.
6. When the structure changes, the value is worked out again with the places it has.
7. Undo takes a change of decimals back in one step.

## How

- `src/proprows.ts`: each row's value takes the places (`d ?? own`). m/z's relative intensities stay at 1 place.
  `placeValues(m, ids, places)` sets or clears `attrs.places` on the live values among the ids, as `nameValues`
  sets their names, through one helper they share.
- `src/Editor.tsx`: `caption.places.<arg>` in the caption commands, beside `caption.names`, works the text out at
  once with the same path (`namedValues` becomes `reworked`). `valuesPicked` also gives the first live value's
  places, for the Actions panel.
- `src/render.ts` `arrowPicks`: a Decimals pick for live values. The Actions panel shows it as a PickButton and the
  right-click menu as a row with a sub-menu, from that one list, as the arrow picks do.
- `scripts/headless/host.ts`: the same commands for AI apps with no window.
- `src/mcp.ts`: `caption.places.(standard|[0-8])` in run_command's list, and `decimals` on edit. The MCP does not
  start in 1.1.3 (features.ts AI false), so none of this shows there.

## ChemDraw cross-check (from Octet's notes, no ChemDraw run)

- ChemDraw 26.1 help, Chemistry Features: the Analysis window's Decimals setting applies to Exact Mass, Molecular
  Weight and m/z only.
- The Chemical Properties window has no decimals setting in the notes. Its values have fixed places.
- A pasted analysis caption updates as the structure changes. Its right-click menu shows or hides each row
  (Analysis > …). The notes list no way to change the decimals of a caption already on the page. To get other
  places in ChemDraw, the user pastes the values again.
- Octet goes further on both: Decimals reaches every number, and a value on the page takes new decimals in place.

## Stress list

1. A live value with places 3 and rows weight, logP and tb: all three show 3 places.
2. Standard on the same value: 2, 2 and 1 places again, and no `places` attribute.
3. Decimals 0: no decimal point in any number (a weight of 180, a logP of 1, a pKa of 4).
4. Decimals 8 on m/z: 8 places on each m/z, 1 place on each intensity.
5. The formula, CAS number and GHS rows do not change with any Decimals.
6. Elemental analysis does not change with Decimals (see Cut).
7. A negative logP with 0 places keeps Octet's minus sign (−1).
8. Decimals on two live values with different places: both take the new places.
9. Decimals on a live value and plain text picked together: the plain text does not change.
10. Decimals on text typed over a live value (no rows): nothing changes, and nothing is added to Undo.
11. The same Decimals again: nothing changes, and nothing is added to Undo.
12. A drawing with a live value at places 5: .oct and CDXML give back places 5. CDX keeps it through CDXML.
13. A file with places "9", "-1", "2.5" or "abc": the value opens and is worked out with each row's own places.
14. A structure edited after Decimals: the value is worked out again with the new places.
15. Decimals while Indigo is still loading: the attribute is set, and the text follows when the live update runs.
16. Undo after Decimals: the old text and the old places.
17. The Properties panel's Decimals at 3: every number row in the panel shows 3 places, and Add to drawing writes
    `places="3"`.
18. 1.1.2 opens a 1.1.3 file with places on a logP value: it reads it (it keeps `places` already), and shows logP
    with 2 places, as 1.1.2 always did.
19. A 1.1.2 file with places 3 on a value with weight and logP: 1.1.3 shows logP with 3 places once it works the value
    out again. This is what Decimals now means.
20. The Decimals pick shows only when a live value is picked. It shows the first picked value's places.
21. Working the values out stays as fast as before: one `?? own` per number, nothing new on the hot path.

## Cut

- Elemental analysis keeps 2 places. Indigo gives the mass percentages to 2 places, and journals report an analysis
  to 2 places. More places would show digits Octet does not have.
- Decimals per row on one live value (logP at 1, weight at 4 in the same text). One setting for the whole value, as
  the Properties panel and ChemDraw's Analysis window have.
- A key for Decimals. ChemDraw has none, and ten choices do not fit one key. The command palette does not list the
  picks, as it does not list the arrow picks.
