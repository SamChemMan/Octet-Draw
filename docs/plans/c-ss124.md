# \oplus and \ominus in typed text (PR #124, for 1.1.3)

Prof. Stefan Schramm's PR #124 has two parts. The key commands for circled charges are in 1.1.3 already (#60).
This item ports the other part: `\oplus` and `\ominus` typed in text give ⊕ (U+2295) and ⊖ (U+2296), the
characters the Character Map already has under Chemistry and that chemfig code writes as `\oplus` and `\ominus`.

Branch `item/c-ss124` from 9ca16e2.

## What ChemDraw does

- ChemDraw has no typed names (escapes are Octet's, issue 25). The Character Map is the ChemDraw way to type ⊕.
- ChemDraw 22.2 writes a character outside Mac Roman as itself in the CDXML `<s>` run, in the run's own font: Sam's
  corpus (68 files, ChemDraw 22.2.0.3348) has π, →, δ and • written that way in Arial. Octet writes ⊕ and ⊖ the
  same way, so nothing changes in `cdxml.ts`.
- A free circled charge is ChemDraw's Symbol graphic, SymbolType CirclePlus or CircleMinus. Octet's free symbols
  (#164) are the same object. Text is text in ChemDraw. Octet 1.1.3 reads a charge typed as text by a structure
  (+, −, 2+) as that structure's own, as it does a free symbol (`mixtures.ts` symbolOwners, 2e6260c1).

## Requirements and how each is tested

1. `\oplus` gives ⊕ and `\ominus` gives ⊖, by the exact-name rule (`\oplusx` stays). escapes.check: table asserts.
2. Every place text is typed takes them: a caption (and a step name), an atom label, a table cell, a stoichiometry
   grid cell, the experiment details and conditions, and the experiment page's markup. These all go through
   `expandEscapes`, `expandRuns` or `ESCAPES`; escapes.check already asserts each call site. New asserts: the markup
   reads `\oplus`, and both characters are in the Character Map and have a name.
3. The characters survive .oct, CDXML and CDX (the clipboard carries the same three). escapes.check: a caption
   `R⊕ + X⊖` written and read back by each, and the CDXML holds the characters themselves in the `<s>` run.
4. A ⊕ or ⊖ typed as a caption by a structure is that structure's charge, as a free circled charge there is: Clean Up
   carries it, it is no reaction plus sign and does not keep a salt's ions apart. `isChargeText` takes ⊕ and ⊖,
   with a number before or after (2⊕, ⊖2). escapes.check: `isChargeText` asserts and a `symbolOwners` case beside
   the same free symbol. ⊕ is never a reaction plus sign, so only "+" keeps the "raised" rule.
5. Chemfig code writes them back as `\oplus` and `\ominus` (already true, `chemfig.ts:42`). escapes.check: one
   assert.

Labels: a label with a sign typed in it (N+, NMe3+) is text to Octet's label reader, so N⊕ is too. No change.

## Design

- `escapes.ts`: Schramm's two entries, `oplus: "⊕", ominus: "⊖"`, cherry-picked with his authorship.
- `mixtures.ts`: `isChargeText` takes ⊕ and ⊖ as signs.
- No change to keys, Editor paths, MCP ops or `releases.ts`. No hot path changes (`isChargeText` runs on captions
  only, and the regex is the same size).
