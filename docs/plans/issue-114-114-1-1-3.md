# Find suppliers from PubChem (#114), for 1.1.3

Issue 114 (Schramm, low priority from his side): for a drawn structure, is it on sale, from whom, in what quantity, at
what price, and what is its CAS number. From free data, with PubChem's supplier list as a start. Sam (9 November):
there is no good free source of supplier and price data yet. Sam approved this for Octet Draw 1.1.3 (Friday
20 November 2026) with AI off.

Branch `item/b-114`, cut from `release-1.1.3` f06d1b49. The Rust half was written for 1.2 on `item/114-suppliers`
(0bd3efdf, plan `docs/plans/issue-114-suppliers.md` on f8ccfd41). This branch ports that Rust by hand (main.rs
differs here) and adds the page side.

## What it must do (every ask)

1. Find suppliers for the selected structure (or every structure the Properties panel shows, at most 12), from:
   the Search menu (Find Suppliers), the Actions panel (Search set), the command palette, the Properties panel (a
   Find suppliers button beside Find hazards).
2. A supplier list: vendor names (each once, A to Z), each a link that opens the supplier's page in the browser,
   then Open in PubChem (the compound's Chemical Vendors section). A list of more than 12 has a field at the top
   that filters it.
3. A busy state and Stop: while a lookup runs, its button reads Stop and the Suppliers row reads "Searching
   PubChem" for the structure being asked. Stop ends the request in flight (Rust) and drops the rest of the queue.
4. Find hazards gets the same: the Search menu's Find Hazards, the Actions panel and the palette run the existing
   lookup (`pubchem_hazards`, the Properties panel's Find hazards) for the selection, with the same Stop.
5. Everything needs Settings > Online search on. Off: the Search menu, the panel buttons, the Actions panel items
   and the palette entries are not there (decision 0008), and any other way in (a key the user gave the command in
   Settings) shows "To find suppliers, turn on Online search in Settings." with Open Settings. Rust refuses too.
6. The CAS number: done already (the CAS number row). Price and pack size: out (no free data).
7. Decision 0008 gets an update section.
8. Checks with a recorded (made-up) PubChem answer; no network in checks.

## How

Rust (`src-tauri/src/pubchem.rs`, ported from 0bd3efdf):

- `pubchem_suppliers(key)`: InChIKey to CID (`/cids/TXT`), then PUG View Source Categories
  (`/rest/pug_view/categories/compound/<cid>/JSON`), read in Rust as hostile: 16 MB and 30 s at most, serde into
  typed fields (a wrong type refuses the whole answer), names cleaned (control and format characters out, spaces
  joined, 120 characters), links kept only as clean https to a named host (else the PubChem substance page), each
  supplier once, A to Z, at most 1000. Returns `{ cid, suppliers: [{ name, url }] }` or none.
- `open_link`: `supplier:<url>` only for a link a `pubchem_suppliers` answer gave this session, and
  `pubchem-vendors:<cid>`; both only with Online search on.
- `pubchem_stop(kind)`: ends the window's lookup of that kind ("suppliers" or "hazards") within a chunk. A closed
  window's lookups end. `pubchem_hazards` takes the same Stop.
- A pace for every PubChem request in the app: 250 ms after the one before (NCBI asks for at most 5 a second).
- Search menu: Find Suppliers and Find Hazards after Search Google Patents, no keys (ChemDraw has none).

Page:

- `src/suppliers.ts`: the answer's shape checked again (`suppliersOf`), the row text, `withSuppliers` (the Suppliers
  row and the PubChem CID from either lookup), the notices.
- `src/proprows.ts`: a Suppliers row in the GHS group, before PubChem CID, filled by `withSuppliers` as the CAS row
  is by `withCas`. It has no Add to drawing box: a supplier list goes out of date, and a drawing never holds it.
- `src/Properties.tsx`: Find suppliers beside Find hazards; each reads Stop while it runs. Each structure's
  supplier count is a `Pick` (src/Menu.tsx) of its suppliers. `Pick` gets one optional prop, `find`: a field over
  its own options when it has more than 12 (the same field and "Nothing matches" as More fonts).
- `src/Editor.tsx`: one runner for both kinds (`lookUp`): the keys the panel shows, each once a window, one at a
  time, Stop by a run number and `pubchem_stop`. The commands `find_suppliers` and `find_hazards` open the Properties
  panel when it is closed and run. Errors: off gives the Open Settings notice; no network or PubChem down gives
  "Octet cannot reach PubChem. Check the network connection." and keeps nothing; Stop gives no notice.
- `src/Actions.tsx`: Find suppliers and Find hazards in the Search set, with Online search on.
- MCP: not in 1.1.3. AI is off in this release (src/features.ts). The 1.2 plan's `advanced suppliers` op stays for
  the 1.2 tree.

## ChemDraw cross-check (from Octet's notes only)

Sources: `~/octet-research/notes/chemdraw26-inventory.md` (Add-ins, Help), `chemdraw-release-notes.md` (strings
gone from 26.1), `help26/text/ChemACX_Explorer_Add_in.txt` and `Viewing_Results_Details.txt`, and the 1.2 plan's
summary of them.

- ChemDraw 26.1 has no supplier command of its own. "Find Suppliers on ChemACX.Com" is a string gone from the 26.1
  binaries (22.2 had it). 26.1's Help links to suppliers.
- ChemACX Explorer (an add-in, downloaded on its own, over Revvity's subscription catalogue) takes the selected
  structure, lists results, and a structure's Sources tab lists each supplier with pack size, cost, purity and
  catalogue number, a filter field, and a link that opens the supplier's site in the browser.
- PubChem GHS LCSS (add-in): Octet's Find hazards.
- No keys for any of these. No CDXML object or attribute carries supplier data (the CDX spec's RegistryNumber and
  RegistryAuthority are not read or written by ChemDraw).

Octet matches: the selected structure, a supplier list with a filter, links to the browser, the CAS number.
Octet differs: no pack size, cost, purity or catalogue number (PubChem has no prices; catalogue numbers are per
product, up to 13 for one supplier); no substructure, similarity or text search (PubChem's vendor list is per
compound; Name to Structure reads names and CAS numbers first).

## Cut, and why

- Price, pack size, purity: no free source has them.
- Catalogue numbers: one supplier can have 13; the supplier's page shows them.
- The MCP op: AI is off in 1.1.3. It goes in the 1.2 tree with the rest of the MCP.
- A per-structure "Searching PubChem" for hazards: the hazards rows appear only once found; the button reads Stop.
- Demo answers and a `npm run look` place for the list: the task forbids starting a dev server here. Sam runs the
  app (below).
