# Issue 117 for 1.1.3: reagent tables out to an electronic lab notebook

Stefan Schramm's issue 117 (his priority: low). He wants a finished scheme and its stoichiometry table in his
university's notebook as a record that still knows its molecules. A documented format is enough. Sam approved this for
1.1.3 (Friday 20 November 2026). Branch `item/b-117`, cut from `release-1.1.3` at f06d1b49. The longer plan for 1.2 is
`docs/plans/issue-117-eln-export.md` on `item/117-eln-export` (d31298f0). This is the part of it that fits Friday, plus
the `.eln` archive that plan cut. Field names are in decision 0029.

## What it must do

1. RDF export (V3000 and V2000) writes each reagent table's values after its record's rxnfile as `$DTYPE` and `$DATUM`
   pairs: for each column Role, Name, Number, Formula, MW, Limiting, Equivalents, Mass, Moles, Volume, Density,
   Molarity, Concentration, Purity, Expected mass, Expected moles, Measured mass, Yield and the rows of the user's own.
2. The record also has the experiment details where set (Title, Exp. number, Date, Notebook, Project, Author,
   Temperature, Time, Pressure, Solvent, Keywords) and the table's conditions.
3. SDF export (V3000 and V2000) writes the same component fields as SD data items on each compound in a table, with
   `Reaction` (its record in the RD file) first and the details last.
4. Octet reads its own RD file back with the same names: the reaction, the text over and under the arrow, the compound
   numbers and the same table, cell for cell.
5. File > More Formats > Export ELN Archive…: an `.eln` file (The ELN Consortium, RO-Crate 1.2) holding the `.oct`, the
   CDXML, and the RD and SD files when the drawing has a reaction or structures.
6. A drawing with no table writes the RD and SD text it wrote before.
7. Checks for the fields, the read-back, the archive and hostile input.

## How

- `src/eln.ts` (new), one module for the editor and the host with no window:
  - `elnRecords(m, reactions, views, at?)`: one RD record for each table. Its reaction is the table's columns: drawn
    reactants, drawn agents (over and under the arrow), drawn products, in column order. A whole-scheme table on two or
    more steps is a record for each step with no fields, then the table's record (first reactants, every agent, last
    products). A step with no table is a record with no fields, as before.
    Also gives each table compound's SD items.
  - `rdData`, `sdData`: the text. RD lines break at column 80 and go on at column 1 (CTfile rule); a break never starts
    a line with `$` or splits a character.
  - `readFields`, `withRecord`: the reader, as hostile input.
  - `elnArchive`: the archive's files and `ro-crate-metadata.json`.
- `src/chem.ts`: `toReaction` takes the fields of each record, `toSdf` the items, `readRdf` reads a record's fields
  (it dropped everything from `$DTYPE` before).
- `src/Editor.tsx`: `chemistryOf` writes RDF and SDF through `elnRecords` (Export, Quick export, Export of the
  selection, an AI app's `read`). The More Formats list gets one line.
- `scripts/headless/host.ts`: `fileText` writes `rdf`, `rdf2000`, `sdf2000` and `rxn2000` as the editor does (it wrote
  only `sdf` and `rxn`).
- `src-tauri/src/export.rs`: `make_eln` zips the files the page sends after checking each path. `convert.rs` leaves
  `eln` out of `--to`.

## Cut, and why

- **ChemDraw's own grid in CDXML and CDX.** The notes on `stoichiometrygrid` are not confirmed with a file ChemDraw made.
- **Damaged RD records left out one by one, with a notice.** One damaged record still fails the file, as in 1.1.2. It
  needs a new notice path on every way in; not for Friday.
- **Reading another program's amounts into a table.** Only Octet's own table field makes a table: another program's
  fields do not say what was typed and what was worked out.
- **Experiment details on import.** The record goes into the open drawing, which has its own details.
- **`--convert --to eln`.** The archive is made by the page from several formats; `--convert` writes one.
- **MCP description clause.** The AI features are off in 1.1.3. `read` with `rdf` and `sdf` already gives the fields
  through the host; the one-line description change waits for 1.2 and the MCP review.
- **`.eln` import.** Octet does not read `.eln` files.

## Speed

No hot path changes. Fields are made only when an RD or SD file is written. The reader's one pass runs only on RD text
with a `$DTYPE` line. 15,000 hostile fields read in well under a second (timed in the check).
