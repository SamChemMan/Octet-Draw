# Octet Draw 1.1.2

This update fixes problems you reported and adds features you asked for.

## Highlights

- A minimised spectrum is now a small pill beside its structure.
- Octet now predicts ¹⁹F and ³¹P NMR spectra.
- The template library has 14 new sets and 211 new templates.
- Every colour menu is now the same, and Pick from screen takes a colour from anywhere on the screen.
- The stoichiometry table now has catalyst and solvent roles, and one table for each step of a scheme.
- On Windows, a drawing pasted into Word now keeps its true size.

## Spectra

- A minimised spectrum is now a small pill beside its structure. Click the pill to show the spectrum again.
- The spectrum and the Actions panel are not open at the same time. When one opens, the other becomes a pill.
- View > Show or Hide Spectrum now minimises the spectrum or shows it again.
- Every panel now has the same controls: Minimise, Full screen and Close.
- Each structure now has its own spectra, as tabs. Click + to add a spectrum. Click X on a tab to remove that spectrum.
- Undo now shows a spectrum again after you close it.
- Mass spec analysis is now in the Actions panel and the Structure menu.
- Drag the top edge of a spectrum to change its height.
- The arrow keys now move between the peaks. A screen reader reads each peak.

## NMR

- Octet now predicts ¹⁹F and ³¹P NMR spectra.
- ¹H and ¹³C spectra now show the splitting from fluorine and phosphorus.
- A ¹⁹F spectrum shows its ¹H couplings. A ³¹P spectrum does not. To change this, use Decouple ¹H.
- Octet now opens measured ¹⁹F and ³¹P spectra. If a file does not name its nucleus, Octet finds it from the frequency.
- ¹H and ¹³C shifts are now more accurate near sulfonyl groups, in heteroaromatic rings and in bridged bicyclic rings.
- Octet now shows OH, NH and SH shifts as Rough, because the solvent changes them.

## Templates

- Seven new sets are for biology: Lab equipment, Cells, Biomolecules, BioArt, Anatomy, Organisms and Bugs.
- Seven more are DNA and RNA, Side chains, Peptides, Polyhedra, Supramolecules, Carbon and Symbols.
- The Lab set has 29 more items, such as a three-neck flask and a Dean-Stark trap.
- The template library now has two filters, Structures and Clip art. A search shows its results in these two groups.
- The new sets load after Octet starts, so Octet starts as fast as before.

## Drawing

- Every colour menu now has the same parts: recent colours, presets, your colours, Pick from screen and Add colour.
- Pick from screen takes a colour from anywhere on the screen.
- Drag your colours to put them in a new order. Right-click a colour to rename or remove it.
- Part of a chemical label can now have its own colour. Select the characters, then pick a colour.
- Colour > By Element now removes the element colours when you use it again.
- Point at an atom and press its element key again to remove one hydrogen. For example, O changes OH to a bare O.
- One bond, such as ethane, is now a molecule that you can name and analyse. One labelled atom, such as H₂O, is also a molecule.
- The Text tool now has a periodic table. Hold the Text tool to open it.
- In a 3D structure with depth shading, the Opacity slider now fades the selected atoms.
- Octet now draws each small fishhook or curved arrow as one smooth curve, also in exports.
- A value that you add from the Properties panel now changes with the structure. To stop this, type new text in its caption.
- You can now set keyboard shortcuts for circled positive and negative charges, in Settings > Keyboard shortcuts.
- Add multi-centre attachment and Add variable attachment have new icons.
- In the Actions panel, one click now closes a section that opened on hover.
- In a window, Return now presses the focused button, such as Cancel.
- On Home, drag a box over drawings to select them. Click Remove to remove them from Home or from the folder.
- Clean Up Reaction now turns each product to match its starting material. Use Undo one time to keep the products as you drew them.
- Octet no longer has Augmented Clean Up Reaction, because Clean Up Reaction now does the same work.
- On the Mac, a pinch on the trackpad now zooms the drawing with no key held.
- In a table from the Table tool, Shift+Return now moves up one cell.

## Stoichiometry table

- Each reactant column now has a role: Reactant, Catalyst or Solvent. Click a cell, then set the role in the Actions panel.
- In a new table, a common solvent on the arrow, such as THF, DCM or MeOH, gets the Solvent role.
- A catalyst now shows its Equivalents in mol%. Type 5 or 5% for 5 mol%.
- A scheme with two or more arrows now gets one table for each step. A product's Measured mass sets its amount in the next step.
- The new Concentration row shows the concentration of the limiting reactant. Type a concentration for a solvent, and Octet calculates its volume.
- Reactants now have Density and Volume rows. The Density row shows the density of 41 common liquids. Type a volume, and Octet calculates the mass and the moles.
- A product's Expected mass now sets the amounts of the starting materials.
- The amount that you measure for each reactant is now red, with a line under it.
- The new Conditions… command puts the Temperature, Time, Atmosphere and Other conditions that you type beside the table.
- The table now includes more reagents from the arrow, such as cat. H2SO4, K2CO3 (2 eq.), H+ and water.
- A coefficient, such as the 2 in 2 A + B → C, now sets the equivalents. A fraction, such as ½ O2, does the same.
- The table now calculates molar masses for 27 more elements, such as Mo, Ba, Ce and Bi.
- A mass with no unit is now in grams. To use milligrams, change Mass without a unit in Settings.
- Copy table copies the table as text for a spreadsheet or a document.
- Hide empty rows hides each row with no value. To show the rows again, use Show all rows and columns.
- The arrow keys and Tab now move between cells. Return starts an edit, and a typed character replaces the value.
- Delete now removes the value in a cell. It no longer removes the whole table.

## Chemistry

- Convert Structure to Name now names more ring systems, such as galantamine, brefeldin A, cefotaxime and the calixarenes.
- The Sequence tool now draws peptides, RNA and DNA with a straight backbone. Clean Up does the same for a chain you draw.
- Octet now pastes HELM and FASTA as a sequence. Edit > Copy As has both.
- Structure > Expand Generic Structure to SDF… saves every structure in a series to an SD file, up to 10,000.
- The Properties panel now shows the CAS number of each structure. With Online search on, Octet gets missing numbers from PubChem.

## Files

- A drawing now has a title, an author and keywords, in Settings > Document > Properties. Octet saves them in the file and in exported PDFs.
- A new drawing gets your computer user name as its author.
- File > Insert… adds a saved drawing or a picture to the open drawing. You can also drop the file onto the drawing.
- Octet now opens and saves ChemDraw style sheets (.cds). Use File > Apply Settings From File… and Settings > Document > Save to file….
- Settings now has a Pro tab. Its More formats switch adds File > More Formats, for rare file formats.
- File > More Formats exports CML, BMP and 3MF, imports and exports connection tables (.ct), and copies SLN.
- Export 3MF… makes a ball-and-stick model for 3D printing.
- File > More Formats opens crystal structures (CIF) and the ligands in mmCIF files. Octet keeps their 3D shape as depth.
- Export LaTeX (chemfig) saves structures as chemfig code.
- Settings > Pro > Selection sets the bond length, line widths and fonts of the selected objects. Copy settings and Paste settings give them to another object.

## Search

- The Search menu now has Search SciFinder, Search Google Scholar and Search Google Patents.
- Search SciFinder opens SciFinder and copies the structure's SMILES, so you can paste it there.
- With Online search on, Find hazards now shows GHS pictograms, hazard statements and precautionary codes from PubChem.

## Windows, Linux and Word

- On Windows, a drawing pasted into Word now keeps its true size. Before, it became 7.5 times as large when you set its size to 100% again.
- On Windows, when Word starts Octet, Octet now waits for the drawing and does not close too early.
- On Windows and Linux, the Window menu now lists the open drawings, with a tick on the drawing in front.
- On Linux, Print and Print Selection now show the pages first, so you can see where the pages break.
- On Linux, we can now make a Flatpak test version of Octet. It helps us find why drawing is slow on some NVIDIA computers.

## Fixes

- A large drawing no longer stops the editor after many edits.
- Octet now tells you if its chemistry engine cannot load.
- A 3D structure with many identical groups, such as triisopropylsilyl groups, no longer stops Octet for minutes.
- Pen curves and clip art no longer show thin gaps along their lines when you zoom in.
- A colour menu now shows each colour at its true strength, so Black no longer looks grey.
