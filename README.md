# Octet

A chemical structure drawing editor for the 21st century.

Status: early development. Octet will be a free, offline desktop app for
Mac and Windows.

## Run from source

You need [Node.js](https://nodejs.org) and [Rust](https://rustup.rs).

```bash
npm install
npm run tauri dev
```
